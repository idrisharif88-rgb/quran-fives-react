# الخطوط المحلية

ملفّات `.woff2` هنا نُزّلت من Google Fonts بـ`scripts/fetch-fonts.sh`، ليعمل
التطبيق بلا إنترنت. لا تُحرَّر يدوياً — أعد تشغيل السكربت لتحديثها أو لإضافة وزن.

| العائلة | الأوزان | الرخصة |
| --- | --- | --- |
| Tajawal | 400, 500, 700, 800, 900 | SIL Open Font License 1.1 |
| Amiri | 400, 700 | SIL Open Font License 1.1 |
| Amiri Quran | 400 | SIL Open Font License 1.1 |
| Noto Naskh Arabic | 400, 700 | SIL Open Font License 1.1 |
| Scheherazade New | 400, 700 | SIL Open Font License 1.1 |

الخطوط الخمسة كلّها تحت رخصة SIL OFL 1.1، وهي تسمح بتضمين الملفّات وتوزيعها
داخل التطبيق. نصّ الرخصة: <https://openfontlicense.org>

النطاقات المحفوظة: `arabic` و`latin` فقط. أُسقطت `latin-ext` و`cyrillic`
و`greek` و`vietnamese` لأن التطبيق لا يعرض شيئاً منها.
